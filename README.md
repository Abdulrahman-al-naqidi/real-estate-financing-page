# Dar-k | Real Estate Financing Landing Page

![HTML](https://img.shields.io/badge/HTML-5-E34F26?logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-3-1572B6?logo=css3&logoColor=white)

An Arabic, right-to-left landing page for a real estate services company. It presents latest listings, services, average prices and customer reviews.

**Live Demo:** https://abdulrahman-al-naqidi.github.io/real-estate-financing-page/

## Features

- Hero section with a call to action
- Latest properties cards (chalets, villas, apartments)
- Services section: consulting, rental, buy and sell, finishing and maintenance, mortgage financing, valuation
- Average prices chart section and customer reviews
- Responsive RTL layout with Google Fonts

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
